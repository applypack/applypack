The full pass the improvement plan asked for
([docs/improvement-2026-09/](./improvement-2026-09/README.md), §24–§27),
run against `main` at `592eb04` (v2.5.2). It starts where
[audit-2026-09.md](./audit-2026-09.md) stopped: nothing on that report's
"checked and clean" list is re-audited here, and its two "left alone"

Method: the cheap deterministic checks were run by hand; five read-only
sweeps (security and privacy; every route handler; every Prisma call site;
every fetcher, AI backend and prompt builder; every page for accessibility
and copy) were run in parallel; **every P1 and every P2 that names a code
path was re-verified by hand against the built code** before it went in
(the SSRF bypasses were probed through `dist/`, the zlib cap through Node
26, the fence sanitiser through `dist/prompt-fence.js`). No code was
changed. No issues were created — the candidates are listed and TASKS §20
carries the work.

**Roll-up: 0 × P0 · 2 × P1 · 27 × P2 · the rest P3.** No data loss, no
secret leak, no auth bypass, no blind-mode PII reaching a model. The two
P1s are one input guard that does not do what its comment says and one
decompressor with no ceiling. The largest class of P2 is "the rule exists
and one site skips it".

### Security

- **SEC-1 · P1 · `src/jobs/posting-url.ts:100–118`, re-check at `:171`** — `isPrivateHost` is a *name* check; nothing inspects the address the name resolves to. Probed through `dist/`: `http://localhost./x`, `http://[::ffff:169.254.169.254]/` and `http://127.0.0.1.nip.io/` all return `{ ok: true }`. A pasted posting URL (or a public one that 302s) can hand a private service's body — on a cloud VPS, the metadata endpoint — to the page and to the model prompt, which is the exact attack the module comment claims to stop. Direction: resolve every A/AAAA record before connecting and refuse private ranges including IPv4-mapped IPv6; `redirect: 'manual'` with the same check per hop; the request must not be made when the check fails (today it is made, only the body is withheld). Block `security-p1`.
- **SEC-2 · P1 · `src/resume/zip.ts:54, 58, 94` and `:36–41`** — `readZipEntries` compares against the archive's own `uncompressedSize` field, `inflateRawSync(data)` has no `maxOutputLength`, every entry is inflated before `MAX_FILES_PER_UPLOAD` applies, and `readZipEntry` (the `.docx` path) has no cap at all. A 200 MB batch upload or a 5 MB `.docx` can inflate to gigabytes and take the web process down. Verified: Node 24+ `inflateRawSync(data, { maxOutputLength })` throws `ERR_BUFFER_TOO_LARGE`, so the fix is the option plus an entry-count and a total-bytes ceiling. Block `security-p1`.
- **SEC-3 · P2 · `src/verification/liveness.ts:351–367`** — a second SSRF guard (`isFetchableJobUrl`) with different rules: stricter on IP literals, no ADR 0005 list, and `!host.includes('.')` as its only "internal" test. Two guards drift; this one has. Direction: one function. Block `security-p1`.
- **SEC-4 · P2 · `src/web/public/target.mjs:247–249, 262–263`** — `escapeHtml` escapes `& < >` but not `"`, and the result lands in `title="…"` of a `<mark>` written through `innerHTML` (`target-page.mjs:158`). The title is built from a keyword term, which arrives from the posting via the model or from the keywords route (`z.string().max(100)`, no charset rule); CSP allows `'unsafe-inline'`. Direction: escape `"` and `'`; the site's vendored copy must change in lockstep (`site-vendor.test.ts`). Block `security-p1`.
- **SEC-5 · P2 · `src/screening/export.ts:59–62`** — `csvCell` quotes but never prefixes; a cell beginning `= + - @` (an applicant's own file name, or model text quoting a resume) is a formula when the recruiter opens the CSV in Excel. Direction: prefix `'` on those leaders. Block `security-p1`.
- **SEC-6 · P2 · `package.json`** — `hono@4.12.15` carries ten advisories; the one on a code path this app uses is the unbounded dot-notation nesting in `parseBody()` (< 4.13.5). `npm audit fix` is a minor bump touching two packages. `node-cron@3` → `uuid` (moderate, a `buf` path this app never calls) needs the 4.x major; separate, low. Block `deps-hono`.
- **SEC-7 · P3** — `routes/health.ts:11` returns the raw Prisma error (host, port, user) to whoever reaches `/health`; `server.ts:62–64` a `WEB_BASIC_AUTH` without a colon fails *open* with a warning; `notify/discord.ts:117–121` the webhook host is checked at creation and never at send (feeds are re-checked every tick — `feed.ts:20–27`); `same-origin.ts:125–129` trusts `X-Forwarded-Host` over `Host`; `routes/resume-render.tsx:52–54` a GET starts an AI run (reachable by `<img src>`, bounded by `claimRun`). Block `route-hardening`.
- **SEC-8 · P3** — no global body limit: `bodyLimit` sits on 9 of ~110 POSTs; the five uncapped free-text writes (ROUTE-3) buffer whatever arrives. Block `route-hardening`.
