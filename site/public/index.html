Why a strong resume gets filtered

      

        

          The filter counts words, not years.
          
A resume that says "PHP 8, Laravel, Symfony" can miss a requirement that says "PHP", and a recruiter never sees it.

        

        

          Half the postings are noise.
          
The wrong stack in paragraph four, "Remote" that means remote in Germany, a listing nobody will ever fill.

        

        

          You end up being the cron job.
          
Refreshing boards, reading, guessing what to change, rewriting the letter. ApplyPack was built during my own search to take that over.

        

      

    

  


  

    

      
Three things it does for you


      

        

          
Find real jobs, not noise

          
    
            
  • 33 kinds of job source every hour. Twelve ATS vendors on the companies you pick, twenty aggregators (the monthly HN thread among them), any RSS feed you paste. Starter packs add a whole segment at once.
    • 
            
  • A classifier with rules that burned me. "Full-stack" in a title is not a stack match; "Remote · Germany" is not US-remote. Up to eight searches at once, one AI call per posting.
    • 
            
  • Is it real? A free liveness check first, then a web-search verdict with evidence links: legit, suspicious, fake.
    • 
            
  • Telegram only above your fit threshold. Paste a posting from anywhere and it gets the same treatment.
    • 
          

        

        
      


      

        

          
Fix your resume for this posting. Honestly.

          
    
            
  • Every keyword the posting wants, graded must / preferred / nice and marked present, missing or confirm-with-you.
    • 
            
  • The model marks facts, code computes the score. No core-stack overlap caps it at 30, Vue is not React, and typing a word is not evidence.
    • 
            
  • Edit side by side with the score updating on every keystroke, free of AI calls. Re-check with AI in about 15 seconds. Save as v2, and the delta against v1 is real.
    • 
            
  • Disagree with the model? Re-level a keyword, ignore it, add the one it missed, or rebuild the list. Your edits survive every re-run.
    • 
          

        

        
      


      

        

          
A cover letter that cannot invent

          
    
            
  • Drafted from the posting, your resume and the facts you confirmed. Nothing else.
    • 
            
  • A fact gate reads every claim back against that evidence. A number that is not in your resume never reaches the letter.
    • 
            
  • Pick a tone, add your own angle. About 30 seconds. Edit in place, export PDF or DOCX.
    • 
            
  • Works for a posting that is not stored yet. Paste it or give the URL.
    • 
          

        

        
      


      

        
And the rest

        
    
          
  • Applications board. Columns you name, drag and drop, which resume each application went out with, a nudge when one goes quiet for two weeks.
    • 
          
  • Guided first run. Connect an AI, test the search, turn a resume into a profile, score the first matches.
    • 
          
  • Five AI engines with failover. Claude Code, Gemini and Codex CLIs on subscriptions you already pay for, the Anthropic API, any OpenAI-compatible endpoint including free local models.
    • 
          
  • Postings cannot hijack the prompt. Every outside text reaches the model inside untrusted-text markers; a test fails the build otherwise.
    • 
          
  • Board discovery. Company boards harvested from HN comments, one click to track.
    • 
          
  • Daily digest and source health. Which boards went quiet, before you wonder.
    • 
          
  • Private by construction. Localhost, no accounts, no telemetry, your own Postgres.
    •

Scores you can argue with

      
Most AI resume tools average their way to a flattering number. ApplyPack splits the job: the model only marks what is present, missing or unverifiable, and a unit-tested formula applies the caps.

      
    
        
  • Primary-stack gate. No core-stack overlap caps the score at 30, however good the rest looks.
    • 
        
  • No sibling credit. Vue is not React, PHP is not Node.js.
    • 
        
  • Unknowns stay unknown. The posting wants profiling and your resume does not say? You get a question, not a guess.
    • 
        
  • Honest deltas. v2 is scored by the same code path as v1, so "+16" means something.

Free, open source, yours to bend

      
ApplyPack is MIT-licensed and has no hosted version: no accounts, no subscription, no telemetry, no ads. You bring the AI: a subscription you already pay for, an API key, or a local model that costs nothing.

      
It is built to be changed. Over a thousand unit tests on the pure modules, a decision record for every non-obvious choice, and a CLAUDE.md that says where everything lives, so a first change takes an evening, with an AI assistant or without one.

      
    
        
  • Add a job sourceClose to a one-file change: three fetcher templates in the repo, a unit test for the mapper, a smoke run.
    • 
        
  • Take a good first issueScoped tasks with file pointers, labelled in the tracker.
    • 
        
  • Bring an ideaOpen an issue with the feature template. Public APIs and RSS only, never scraping; everything else is on the table.

Install in four commands

      
Postgres, the worker and the dashboard from one compose file. A laptop or a $5 VPS is the whole deployment.

      

        

        
git clone https://github.com/applypack/applypack.git
cd applypack
cp .env.example .env    # nothing to fill in yet
docker compose up -d    # → http://localhost:4747, a four-step setup opens

      

      
Paste an AI key on the first screen, or let the dashboard detect the CLI you are already logged into. Fetching starts paused until you finish the setup, so a blank profile never burns your quota.

      
    
        
  • Claude Code CLI, your subscription
    • 
        
  • Gemini CLI, free tier
    • 
        
  • Codex CLI, your subscription
    • 
        
  • Anthropic API
    • 
        
  • Any OpenAI-compatible endpoint, local models included

Engines chain with automatic failover. Consumer-subscription terms do not spell out background services; read yours before making a subscription the primary engine.
